# Documentation

Reference documentation for the Loan Default Prediction project — a Random
Forest classifier that estimates the probability of serious borrower
delinquency, served through a FastAPI backend and a React frontend.

> **Educational prototype.** Built on a public 2011 dataset for coursework. Not
> a credit-underwriting system. See [09-limitations.md](09-limitations.md).

## A note on the numbers

Every figure quoted in these documents comes from
`backend/ml/artifacts/metadata.json` and `evaluation_report.json`, written by
the training and evaluation scripts. Nothing is transcribed by hand, so the
documentation cannot drift from the model that was actually trained.

Working material — the seminar deck, the report, the original brief and the
scripts that generate them — lives in [`../dev/`](../dev), not here.
